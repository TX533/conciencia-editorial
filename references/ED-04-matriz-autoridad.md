======================================================================
PROPÓSITO
======================================================================

La Matriz de Autoridad Editorial define:

- Quién puede hacer qué.
- Quién puede aprobar qué.
- Qué decisiones son automáticas.
- Qué decisiones requieren intervención humana.
- Qué decisiones están prohibidas para cada actor.

Este documento constituye la autoridad máxima
para la asignación de responsabilidades dentro
de la Editorial Digital.

======================================================================
PRINCIPIO FUNDAMENTAL
======================================================================

La IA ejecuta.

El editor decide.

El autor valida.

El administrador certifica.

======================================================================
REGLAS DE APROBACIÓN
======================================================================

Una obra puede avanzar de fase cuando:

✓ La fase actual está certificada.

✓ No existen hallazgos críticos abiertos.

✓ No existen bloqueos legales.

✓ El Pasaporte Editorial está actualizado.

======================================================================
REGLAS DE PUBLICACIÓN
======================================================================

Una obra puede publicarse únicamente cuando:

✓ SK-07 certifica APTO.

✓ SK-09 certifica APTO.

✓ SK-10 genera expediente completo.

✓ Editor aprueba.

✓ Autor aprueba.

✓ Administrador libera.

======================================================================
REGLAS DE BLOQUEO
======================================================================

Cualquier actor con autoridad puede bloquear
el avance cuando exista:

- Riesgo legal.
- Hallazgo crítico.
- Evidencia incompleta.
- Trazabilidad insuficiente.
- Corrupción documental.

======================================================================
CONFLICTOS DE AUTORIDAD
======================================================================

En caso de conflicto:
